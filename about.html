О проекте OpenData KZ

OpenData KZ — учебный веб-проект для изучения, поиска и обработки открытых статистических данных Казахстана.

Цель проекта

Научиться получать данные через API, обрабатывать их с помощью алгоритмов, измерять время работы и сохранять результаты в файл.

Источник данных

В проекте используется API Всемирного банка. Данные относятся к Казахстану и включают численность населения, ВВП, ожидаемую продолжительность жизни и использование интернета.

Алгоритм работы

  1. Пользователь открывает главную страницу.
  2. Программа отправляет запросы к API.
  3. Ответ сервера преобразуется в список записей.
  4. Пользователь задаёт поиск и фильтр.
  5. Программа выполняет линейный поиск.
  6. Найденные записи сортируются пузырьковым методом.
  7. Время обработки показывается на странице.
  8. Результаты можно сохранить в CSV.

Использованные технологии

  • HTML — структура страницы.
  • CSS — оформление и адаптивный дизайн.
  • JavaScript — запросы API и алгоритмы.
  • JSON — формат ответа API.
  • CSV — формат сохранения результатов.
  • Git и GitHub — контроль версий и публикация.

Безопасность и ограничения

Проект не собирает персональные данные и не требует регистрации. Источник данных указан на сайте. Значения могут обновляться на стороне поставщика.

Для корректной работы требуется подключение к интернету и доступность API. Пузырьковая сортировка используется для учебной демонстрации и не предназначена для обработки очень больших массивов.
