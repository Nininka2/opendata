# OpenData KZ

Учебный проект по информатике для работы с открытыми данными Казахстана.

## Цель

Получение, поиск, сортировка и сохранение статистических данных.

## Возможности

- Загрузка данных через API
- Поиск по названию и году
- Фильтрация по показателям
- Пузырьковая сортировка
- Измерение времени обработки
- Экспорт результатов в CSV
- Страница с описанием проекта и источников

## Источник данных

Всемирный банк:
https://data.worldbank.org/country/kazakhstan

API:
https://api.worldbank.org/v2/country/KAZ/

## Технологии

- HTML
- CSS
- JavaScript
- JSON
- CSV
- Git
- GitHub

## Запуск

1. Скачайте или склонируйте репозиторий.
2. Откройте папку в VS Code.
3. Запустите index.html через Live Server.
4. Убедитесь, что есть подключение к интернету.

## Алгоритмы

Линейный поиск — O(n).

Пузырьковая сортировка — O(n²) в худшем случае.

Время обработки измеряется с помощью performance.now().

## Безопасность

Приложение не собирает персональные данные пользователей.
Используются общедоступные статистические данные.
